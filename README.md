# Inamdar KDS — Kitchen Display System

Real-time kitchen order display system for live ticket tracking, prep station management, and instant food-ready notifications.

## Features
- **Live KOT Receipts Rail:** Uniform-height receipt cards with elapsed timers, color-coded delays, table identifiers, and biller details.
- **Item-Level Preparation Toggles:** Interactive toggle switches to mark dishes preparing or ready on the fly.
- **Consolidated Prep Stations:** Left-side prep rail showing aggregated dish counts by station (Kabab, Starters, Rice & Noodles, Soups, Curries).
- **Section Filtering:** Synced with Captain App (`AC`, `FAMILY AC`, `PARCEL`, `HOME DELIVERY`, and `DELAYED`).
- **One-Tap Food Ready:** Instant full-ticket bump that sends real-time alerts back to the floor captain.
- **Audio Feedback:** Real-time kitchen order bell and dish cancellation chimes.

## Getting Started

### Prerequisites
- Node.js (v18+)
- npm or pnpm

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Production Build
```bash
npm run build
```
